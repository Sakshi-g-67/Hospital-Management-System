# Hospital Management System

## Project Description
The Hospital Management System is a computer-based application developed using Python and MySQL.

It helps manage hospital information digitally instead of maintaining records manually.

## Technologies Used
- Python
- MySQL
- MySQL Workbench
- SQL

## Features
- Hospital data management
- Database connectivity using Python and MySQL
- Store and manage hospital information

## Project Files
- `DBMS.py` – Python database management and connectivity code.
- `hospital_management.sql` – MySQL database backup (to be added).

## Database
MySQL is used as the database for storing hospital information.

## How to Run
1. Install Python.
2. Install MySQL Server and MySQL Workbench.
3. Import the SQL database into MySQL.
4. Configure your MySQL connection details in the Python code.
5. Run the Python file.
